# JobTrack
JobTrack is a lightweight job application manager built as a static web app.

## Features
- Dashboard metrics for active applications, interviews, offers, and response rate
- Six-stage application pipeline
- Add and update applications
- Search and filter
- Next-action tracking and simple insights
- Browser persistence with localStorage
- Responsive layout

## Run locally
Open index.html in a browser. No build step or backend is required.

## Project
This MVP was created as a practical portfolio project for a class deployment assignment. See CLASS_NOTEBOOK.md for the process log.

## Future ideas
Authentication, cloud sync, reminders, calendar/email integrations, CSV export, and richer analytics.
